# 90分钟授课安排与材料使用说明

本次培训为**一场90分钟**，聚焦 Microsoft 365 Copilot。课件第1–32页为课堂主讲，第33–41页为课后参考，不计入90分钟，也不在课堂逐页讲解。本说明只规定授课时长与内容，实际日期、时段、场地以组织方确认为准。

课堂完成两项任务：先用三份虚构资料整理绿色办公周项目接手简报，再观看一个会议跟进 Agent 的完整演示，并在权限允许时自测。其他 Agent Lab 留到课后练习。

## 课前准备

- 使用 Philips 工作账号，提前打开 [Microsoft 365 Copilot](https://m365.cloud.microsoft/chat)，确认能进入聊天并添加课堂TXT资料。
- 讲师提前检查 Agent Builder 的创建与测试入口，准备可用的会议跟进 Agent 和演示结果。学员能否创建 Agent 取决于各自权限。
- 在培训群内发放三份原始TXT资料及《绿色办公周三份练习资料说明》，请学员提前下载。无需要求学员访问讲师本地文件路径。
- 本课堂不要求连接 Outlook 或 Teams。会议跟进演示使用同一份虚构“绿色办公周会议纪要”原文，不使用真实邮件或会议内容。
- 使用《04_课堂示例提示词与Agent配置_90分钟.txt》中的配置。Name为“会议跟进助手（课堂练习）”，两个Starter为“整理纪要”和“核查缺口”。
- 若无法访问邮件模板文件，在 Instructions 中直接写明固定输出：摘要（区分已确认决定与讨论事项）、行动项表、邮件草稿。缺失信息保留待确认，不把模板访问成功作为课堂前提。

## 两项任务的使用方式

### Copilot：绿色办公周项目接手

将“项目简介”“会议纪要”“时间表”三份TXT一起加入Copilot。课件中的提示词是示例，学员可以调整措辞，但应保留来源范围与核查要求。课堂输出包括项目接手简报、行动项表和跟进邮件草稿。

核查时重点看：

- 报名开放日期有两个版本：项目简介为8月28日，时间表为8月31日。应保留各版本及来源，并标记待确认。
- 8月27日公告审批与8月28日公告发布可能是先后节点，不应直接当成同一事项的日期冲突。
- 工作预算为CNY 25,000，不能据此填写合同金额。供应商或其他未提供的信息应写“资料中未找到”。
- 行动项的状态只代表资料中的历史记录。不能根据今天的日期推断逾期、未开工或已完成。

三份资料均为虚构培训数据，原日期和状态保持不变。邮件只生成草稿，不在课堂发送。

### Agent Builder：会议跟进

课堂按第21页流程图完成一次演示。第25页说明步骤5邮件模板，第26页说明步骤6能力设置，第29页演示Share。各步骤以本账号界面和权限为准。

正常测试使用同一份虚构“绿色办公周会议纪要”原文，使用文件或原文粘贴均可。输出统一为摘要（区分已确认决定与讨论事项）、行动项表、邮件草稿。核对每项决定、负责人和日期是否有输入依据，缺失内容保留待确认。

信息缺失测试必须**另开一段新对话**，不附完整会议纪要，也不附其他原始文件。只粘贴《04_课堂示例提示词与Agent配置_90分钟.txt》中的完整“信息缺失测试”段。该段有意省略“确认五天议程”的负责人和截止日期，结果应保留“待确认”，不能从资料全文或此前对话补回Programme Lead和8月21日。

75–80分钟的5分钟自测用于运行并核对上述两种输入，不要求学员从零完成所有配置。具备权限的学员可在已有Agent上测试；未具备权限的学员观察演示并记录问题。课堂验收以能否说明输入、输出和核查方法为准，创建或分享未成功时如实记录。

## 故障替代与课后使用

| 课堂情况 | 处理方式 |
| --- | --- |
| Copilot无法登录或上传失败 | 先观看讲师演示，用原始资料核对屏幕上的输出；记录账号或上传问题，课后恢复后补做。 |
| Agent Builder入口或创建权限不可用 | 观看讲师的完整演示，并对照流程和会议纪要检查结果；不将观看演示记为已创建Agent。 |
| 模板或知识源无访问权限 | 在Instructions中写明输出结构，测试时添加虚构会议纪要原文。实际业务知识源的权限另行确认。 |
| 网络或服务响应过慢 | 使用课件中的现有结果示例讲解核查方法，保留练习问题，恢复后继续测试；不声称已生成新的结果。 |

第33–37页提供AI Tool Lab及四个Agent Lab的课后参考，第38–41页介绍AI Skills Navigator和MS-4004学习资源。课堂只说明如何继续学习，不追加逐页讲解。课后可按岗位选择一个Lab独立完成，再带着具体输入、输出和问题寻求支持。
