# 90分钟授课安排与材料使用说明

本次培训为**一场90分钟**，使用53页课件，包含四个Agent Lab的介绍、操作步骤和任选实践任务。

前置介绍控制在15分钟，Copilot实操25分钟，Agent Lab45分钟，答疑5分钟。讲师演示Lab 03会议跟进助手，学员在20分钟实践时段任选Lab 01–04中的一个。实际日期、时段和场地以组织方确认为准。

## 课前准备

- 使用Philips工作账号，提前打开[Microsoft 365 Copilot](https://m365.cloud.microsoft/)，确认聊天、添加文件以及所需Agent Builder入口可用。
- 在培训群内发放三份原始TXT资料、《绿色办公周三份练习资料说明》和《04_课堂示例提示词与Lab操作入口_90分钟.txt》。学员直接从群内下载资料。
- 讲师提前打开[AI Tool Lab](https://philips-ai-tool-lab.github.io/ai-tool-lab-preview/)，按Lab 03完整配置预演，确认Outlook、Teams及一份语言对应的Mail Template可用。
- 学员先了解所选四个Lab各自的资料与权限要求。Product Manual需要相应手册访问权限，会议跟进需要模板，Funnel需要Excel和PPT两份文件。Chief of Staff使用本人真实M365数据。
- Lab 03沿用网站中的模板、工作内容来源和测试要求。权限不足时采用观察与记录方式。

## Copilot练习：绿色办公周项目接手

将“项目简介”“会议纪要”“时间表”三份TXT一起加入Copilot，使用配套04文件中的完整提示词。输出包括一页项目接手简报、行动项表和内部跟进邮件草稿。

核查时重点看：

- 报名开放日期保留两个版本及来源：项目简介为8月28日，时间表为8月31日，标记待确认。
- 8月27日公告审批与8月28日公告发布是不同动作，不直接认定为同一事项的日期冲突。
- CNY 25,000是工作预算，不能写成签约合同金额。150人是报名目标，80%是已报名者出席率目标，400人是合资格内部受众，4.2/5是反馈目标。
- 供应商、合同等信息按原文记录处理。时间表状态只表示资料记录，不能根据今天日期推断逾期、未开工或已经完成。

三份资料均为虚构培训数据，保留原日期和状态。邮件只生成草稿，不在课堂发送。

## Agent Builder：保留原四个Lab

第37–44页介绍AI Tool Lab、流程和四个场景。原流程页已移到案例之前，对应本版第39页。第45–52页用于Lab 03演示，第53页保留从四个Lab中任选一个的完整实践要求。

| Lab | 数据、知识源与能力 | 主要检查点 |
| --- | --- | --- |
| Lab 01 Chief of Staff | 本人真实M365日历、会议、邮件和任务，无需额外外部知识源。 | 三个Starter prompts可用，优先级与冲突有实际来源，数据缺失时不虚构工作事项。 |
| Lab 02 Product Manual FAQ | 指定Product Manual知识源，开启Cloud files并确认AI Adoption，关闭无关来源。 | 创建者与接收者能打开真实手册，资料内问题有可打开引用，资料外问题拒答。 |
| Lab 03 Meeting Follow-up Assistant | 开启Outlook和Teams，添加与输出语言一致的一份Mail Template CN或EN。 | 保留内部行动计划、客户邮件、领导摘要三类输出，完整测试指令与纪要一起提交，打开模板引用核实，缺失信息标待确认。 |
| Lab 04 Funnel Data Analyst | 同时添加Funnel Sample Data.xlsx和Chart Sample.pptx，开启创建文档与创建图片。 | 数据范围明确，台数与金额口径正确，分类顺序和单位准确，保留PPT图表更新选做挑战。 |

配套04文件提供四个Lab入口和检查摘要。**Description、完整Instructions、Starter prompts及测试内容从各Lab网站页面整段复制**，以原场景要求配置。保留原有知识源、能力和检查清单，不能用摘要替代完整规则。

Lab 03演示使用网站的“完整测试提示词｜领导汇报摘要”，同时复制任务指令和培训会议内容。课件中的结果是既有Lab示例，实际测试时需打开模板引用并核对栏目。Agent声称使用了模板本身不构成验证。

20分钟实践用于完成所选Lab的配置和测试，不要求连续做完四个Lab，也不保证每位学员都能在20分钟内完成所选Lab。每位学员记录已完成步骤、正常任务结果、异常条件测试结果及待解决问题。尚未通过检查的项目继续保留原要求，不记为完成。

## 课堂问题处理

| 课堂情况 | 处理方式 |
| --- | --- |
| Copilot无法登录或添加资料失败 | 观看讲师演示，对照三份原始资料核对输出，记录账号或上传问题。 |
| Agent Builder入口或创建权限不可用 | 观察完整操作并记录步骤、检查结果和问题，不声称已完成创建。 |
| 手册、模板或其他知识源不可访问 | 记录无法访问的来源及未通过的步骤，观察讲师验证过程。保留原Lab配置，不使用自拟模板替代。 |
| 网络或服务响应过慢 | 用课件中的既有示例讲解检查方法，注明是已有结果，不声称生成了新结果。 |
| 20分钟内未完成所选Lab | 记录当前步骤与未通过检查，在答疑时提出具体问题；未完成项保持未完成状态。 |

## 材料使用范围

页码用于现场导航。课前准备和配套文件用于减少下载、搜索及复制耗时，讲师按时间安排讲解关键内容，并结合页面完成操作。

AI Tool Lab网站其余六个Lab仍可在课后探索，它们不改变本场原有四个Lab的课堂范围。课后也可继续完成本次尚未通过的步骤，确认实际结果后再更新完成记录。
