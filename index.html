Agent Builder 路线

4 个 Agent 共用的 8 步流程

这是 4 个 Agent Builder Lab 共用的流程。Copilot 笔记本和内容库使用各自页面中的步骤。

01

进入 Agent Builder

打开 Microsoft 365 Copilot，在左侧找到 Agents；电脑端可使用网页或 Teams，iPad 需请求桌面网站。

02

新建 Agent

点击 Create Agent，进入创建界面。

03

选择构建方式

三选一：自然语言生成、Skip to configure 手动配置，或从 Plan my day 等模板开始。

04

填写核心字段

配置 Name、Description、Instructions 与可选 Icon；Instructions 决定任务、规则与输出方式。

05

添加并验证知识源

按场景连接 SharePoint、Teams、Outlook、外部网站、OneDrive 或本机文件，不要扩大不必要的数据范围。知识源名称出现后，还要用一条可命中问题和一条无答案问题验证检索与拒答行为。

06

设置能力

根据场景开启创建文档、创建图片等能力。

07

添加建议提示

把高频任务变成用户一键可用的 Starter prompts。

08

测试、创建、分享

在 Preview 中用真实场景多轮验证，必要时通过左侧对话优化；确认后点击 Create，再分享给同事。

开始前

开始前检查

先确认许可证、入口与资料权限，避免在知识源连接或分享环节中断。

01

Microsoft 365 Copilot

确认账号具有 Copilot 许可证，且公司管理员已开放 Agent Builder。

02

优先使用电脑端

可从 microsoft365.com/chat、office.com/chat 或 Teams 桌面/网页客户端进入，并在左侧打开 Agents。

03

移动设备有差异

iPad 需使用受管理设备，在 m365.cloud.microsoft 请求桌面网站；Teams App 仅支持使用 Agent。手机也建议仅用于使用。

04

确认许可证与资料权限

SharePoint 与 OneDrive 检索要求使用者具备相应的 Microsoft 365 Copilot 许可，并对目标文件或文件夹至少拥有读取权限。分享 Agent 不等于自动授予全部资料权限；创建者和每位最终使用者都要分别确认。

配置说明

Agent Builder 的四个核心字段

不同 Agent 的内容会变化，但这四个字段的作用不变。Instructions 中的来源限制和防杜撰规则必须完整保留。

最多 30 个字符

Name

简洁且唯一，便于在 Agent 列表中识别。

最多 1,000 个字符

Description

帮助 Copilot 判断何时调用，也会显示在应用目录中。

核心行为规则

Instructions

定义角色、任务、限制、输出方式和示例。文档中的防杜撰护栏不能删减。

可选

Icon

用于区分不同 Agent，不影响核心能力。
