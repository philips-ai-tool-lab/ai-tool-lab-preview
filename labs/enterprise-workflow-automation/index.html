Workflow Agent

把一个重复工作流沉淀为可测试的 Codex Skill，并进一步创建可复查的自动化任务包。

约 45 分钟入门Codex · Skill · Automation

练习目标

一个经过首轮测试的可复用 Skill，以及一个可按固定节奏运行的 Workflow Agent。

推荐方式：Codex App + Skill + Automations

练习结果— 一个明确边界的 Codex Skill— 一次真实输入的测试结果— 一份自动化工作流包
SKILL

先把工作流做成可复用能力

技能边界越清楚，自动化越容易被复核和维护。

01

打开 Codex

在桌面应用中开始新任务，确认使用的是批准的工作账号与环境。

02

上传材料并定义范围

点击 +，选择 Add photos & files，上传已经批准用于练习的策略材料或一页业务说明。说明业务单元、工作流和期望价值。

WORKFLOW DISCOVERY PROMPT
I have uploaded the Philips AI strategy document.

I work in [your business unit, function, or region].

Based on the relevant one-pager and uploaded document, help me choose one routine workflow where a reusable Codex skill could create practical value. Ask me one or two questions at a time.
03

选择一个可重复的工作流

优先选择输入、输出和人工复核点都清晰的高频任务；一次只聚焦一个工作流。

04

连接必要插件

仅连接任务真正需要的插件或来源；先搜索并核对用途与权限范围。

05

创建第一个可复用 Skill

用 Launch Intelligence Prompt 或模板创建 Skill，明确输入、输出、假设和必须由人复核的部分。

SKILL PROMPT
Create a skill called "[your skill name]".

Review: [your sources]

Create a skill that: [step 1], [step 2], [step 3].

Return: [output 1], [output 2], [output 3], assumptions, missing information, and human review points.
06

测试并迭代

通过 $ 调用 Skill，加入真实但可使用的测试输入；只修改一个最重要的规则后，用同一输入复测并比较变化。

07

创建并运行自动化

在 Automations 中选择 Create via chat，明确节奏、范围、要调用的 Skill、保存位置与人工复核点；先运行一次检查输出。

AUTOMATION PROMPT
Create an automation called [your workflow agent name]. Every [cadence], review the latest approved sources for [scope], run the required skills, and combine status, risks, actions, human review points, and one visual artifact into a review package. Run it once now so I can inspect the output.
AUTOMATE

让验证过的 Skill 定期工作

自动化先试运行，再决定是否纳入真实节奏。

选择重复工作流

I have uploaded the Philips AI strategy document. I work in [your business unit, function, or region]. Based on the relevant one-pager and uploaded document, help me choose one routine workflow where a reusable Codex skill could create practical value. Ask me one or two questions at a time.

创建 Launch Intelligence Skill

Create a skill called "Launch Intelligence". Review launch trackers, launch calendars, product plans, and reporting documents. Create a skill that analyses launch schedules, identifies launch risks and readiness gaps, and creates a launch readiness dashboard and timeline. Return launch status summary, risks, readiness visualisations, recommended actions, and human review points.

创建自动化

Create an automation called "[your workflow agent name]". Every [cadence], review the latest [source systems and documents] for [scope]. Run $[your skill name] and relevant supporting skills. Combine status summary, risks and readiness gaps, stakeholder actions, human review points, and one visual artifact into one review package. Run it once now so I can inspect the output before saving it.
