# YiQiu 的 Philips AI 工具实验资料归档

## 用途

本归档用于把 AI Tool Lab 项目交接给后续维护人员。内容只保留培训范围、主要入口、资料来源和必要操作说明。

## 交接内容

- **链接台账**：Gateway、Navigator、Tool Lab、Copilot，以及 Notebook 和 Library 的官方资料来源。
- **实验说明**：10 个实验的范围和来源边界。
- **SharePoint 说明**：向 Agent Builder 添加资料时的链接处理方法。
- **邮件附件**：原始培训指南和 Enterprise ChatGPT 入口说明。
- **练习资料**：虚构的“绿色办公周”文件，用于 Notebook 和 Library 实验。

## 培训范围

- 以 AI Gateway 作为了解 Philips AI 工具的起点。
- 以 Microsoft 365 Copilot 作为主要练习工具。
- 通过 Philips AI Tool Lab 完成 10 个分步实验。
- 通过 AI Skills Navigator 查找后续学习资源。

## 来源说明

- 初始 4 个 Agent Builder 实验依据邮件附件中的培训指南整理。
- Notebook 和 Library 实验依据 Microsoft 官方资料自行设计。
- Enterprise ChatGPT 的 4 个实验已整理为站内培训页面。
- “绿色办公周”是培训用虚构案例，不是实际 Philips 项目。
- Enterprise ChatGPT 入口说明含受控凭据，不应上传到公开仓库。
